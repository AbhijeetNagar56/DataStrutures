### 💻 How to Use
Each language folder contains a dedicated shell script (`c.sh`, `cpp.sh`) to streamline the compilation process.

**To run a C++ solution:**
```bash
cd cpp # Place cpp.sh in working dir
bash cpp.sh <filename> # Or compile manually: g++ filename.cpp -o out && ./out
```
